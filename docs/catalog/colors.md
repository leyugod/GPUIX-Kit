# 颜色组件

v0.11.0 新增 ColorSwatch、ColorWell、ColorField、ColorPalette、ColorPanel、ColorPicker。

- [完整 API、原生边界与示例](../../packages/uikit/docs/colors.md)
- 展示：bun run dev:colors
- 原生：bun run test:colors、bun run test:colors:narrow、bun run test:colors:states
- 真实窗口：bun run test:live:colors

覆盖十六进制草稿/提交、8 位 RGBA、透明棋盘、分页调色板、Apply/Cancel/Clear、外部值替换、点击命中与拖动焦点。系统取色、HSV/HSL 面板、渐变、广色域和 AX 仍不在本批范围。
