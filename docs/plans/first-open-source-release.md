# 首个 GitHub 开源版本：范围与验收

2026-09-14 更新：用户要求补齐缺失 UI components 后才能提交 GitHub。当前版本 **0.19.0**，以 [85 类目录映射](../untitled-ui-coverage.md)、[公开契约](../../packages/uikit/docs/catalog-completion.md)和[验收记录](../releases/validation-0.19.0.md)为准。0.18 的收窄清单保留为历史记录，不作为当前完整性标准。

## 组件交付

- 官网 30 类基础、37 类应用、18 类营销组件，全部映射到公开原生封装。
- 统一 Darwin 深浅主题、受控值、操作意图、错误反馈、可组合内容插槽。
- 日期、图表、二维码、筛选、选择等纯模型，以及窗口、文件、媒体、偏好等适配接口。
- Apple 风格来源侧栏、两栏/三栏和 Inspector 保留；新增事件日历、媒体控件、分块富文本、评分/验证码和营销组合。
- 公开类型、组件指南、Gallery、固定依赖、许可证、CI 和可重复执行的原生/包/源码验证。

这是目录类别的原生组件契约覆盖，不宣称每个商业视觉变体、浏览器编辑引擎或完整 macOS 系统行为等价。视频画面由应用提供播放表面，默认富文本采用块编辑；这些边界逐项写入指南。全页业务产品、商业素材资源与服务实现不属于组件移植范围。

## 使用方负责

| UI / 接口 | UIKit 负责 | 使用方负责 |
| --- | --- | --- |
| 列表/表格/视图 | 展示、选择、筛选表达式、偏好草稿 | 数据库、查询、存储与同步 |
| 文件/图片 | 选择意图、预览、状态、失败反馈 | 系统权限、内容读写、上传与下载 |
| 视频 | 控制条、状态、命令锁、播放表面插槽 | 媒体解码、播放、系统全屏实现 |
| 账户/工作区 | 菜单、动作、禁用/加载 | 登录、鉴权、租户 |
| 联系/订阅/消息 | 内容、输入、提交锁与操作意图 | 邮件、传输、订阅、AI 与任务后端 |
| 宿主端口 | 类型、能力和明确结果 | 注入实现、配置、授权与生命周期 |

缺省端口明确不可用，不在 Promise 完成后虚构业务成功。高级业务服务不计为 UIKit 缺失组件。

## 发布验收

执行 check、docs:api:check、check:catalog、test:native:all、test:live:catalog、test:package 和 test:source。目录检查必须通过全部 85 类；源码审计必须有当前版本全部原生脚本的通过记录。独立包测试验证真实导出与操作；源码归档解包后核对内容哈希、文档链接，并在干净目录重新冻结安装和执行类型/规则/目录检查。

版本按整数 minor 递增。GitHub 公开上传单独记录；未指定目标仓库时保持待提交。平台仅声明实测 macOS arm64；远端 CI 未运行、Windows/Linux 原生以及完整 AX/IME 未验证。虚拟化、拖放、原生材质和更深的编辑行为继续在[深度能力矩阵](../component-coverage.md)中如实记录，不能与官网目录类别数量混算。
