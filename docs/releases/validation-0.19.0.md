## 本轮修正与验证深度

- 实际截图揭示 GPUIX SVG 单色蒙版差异：QR 改为原生白底与透明黑色路径，图表按颜色分层。QR 编码矩阵、UTF-8 和四种实际 PNG 截图都由独立 jsQR 解码成功。
- 多停靠渐变改用原生两色渐变小段；评分和图例使用保留颜色的图标插槽。人工查看宽窄截图与真实窗口截图，检查深浅颜色及布局。
- 日历外部集合缩小时钳制页码，避免停留空页；对应测试通过。修正新增测试的字符串 ID 排序预期后，完整 56 脚本重新通过。
- 独立包测试固定测试工具的 Node/undici 类型版本，解决离线缓存中不存在浮动新版本的问题；真实安装和原生消费者通过。

## 交付边界

UIKit 只提供组件、纯模型和适配接口。视频需要应用注入播放表面/解码与控制端口；默认富文本为带撤销/重做的块编辑，任意内联选区由专门宿主表面承担。事件日历不含循环规则、时区换算和小时冲突布局。全页产品、业务服务和私有 PRO 资源未移植。

原生验证仅覆盖本机 macOS arm64；真实文本注入不等于完整 IME 组合输入认证。Windows/Linux 原生、完整 AX、系统材质和拖放等深度能力未声称通过。本文记录本地验收；远端 CI 状态见 [Actions](https://github.com/leyugod/GPUIX-Kit/actions)。

源码与包的 SHA-256 位于 artifacts/0.19.0-SHA256SUMS.txt；构建产物及执行日志不嵌套进源码归档。可运行 test:source 重复检查最终归档。

## 输入垂直对齐修复

公共 Input 对固定 GPUIX 0.7.0 显式设置 flex 垂直居中；Textarea 保留顶部编辑。修复前默认文字中心偏上约 3.75 px，自定义 56 px 高度偏上约 13.75 px；修复后普通文字/占位符/数字在 0.5 px 内，含中文/图标字形的整个测试范围在 1.25 px 内。测量基于实际 PNG 内容而不是 style 属性，完整 57 个原生脚本、真实窗口和独立消费者重跑通过。截图与测量文件在 artifacts/input-alignment-*.png、artifacts/input-alignment.json。
