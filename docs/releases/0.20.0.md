# v0.20.0 · 安装、模板与组件手册

本版补齐三个使用入口：

- GitHub Release 提供固定版本的 UIKit tgz、最小窗口与侧栏模板、源码归档和 SHA-256 清单。
- 两个模板可在仓库外独立安装运行；侧栏模板演示 SourceListSidebar、NavigationSplitView、设置页和主题切换。
- 默认 Gallery 改为统一手册，85 个分类均有独立示例、深浅预览、Code 与 Props。文档参数由真实 TypeScript API 自动生成。

分类与搜索参考 [Untitled UI](https://www.untitledui.com/resources/icons)。目录使用 kebab-case，公开组件维持已有 PascalCase 名称和 API；不增加业务服务、不更改组件数量声明。原有专题 Gallery 继续保留，原默认页面可用 `bun run dev:legacy`。

[快速开始](../getting-started.md) · [组件手册](../components/index.md) · [验收记录](validation-0.20.0.md)

依赖固定 GPUIX/native 0.7.0、React 19.2.4、Bun 1.4.2。平台与宿主限制沿用 [兼容性记录](../compatibility.json)。npm 未发布。
