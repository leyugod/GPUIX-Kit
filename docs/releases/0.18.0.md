主题均基于 Darwin 风格语义 tokens，提供受控浅色/深色与品牌色覆盖。OS 主题监听与持久化属于应用。组件契约、数量上限和键盘约定以对应文档为准；不把基础实现宣称为系统控件完全等价。

## 新增与兼容

0.18.0 新增六个表格偏好组件、纯偏好/排序模型和 HostPorts，DataGrid 新增可选 density，默认 regular。既有公开入口保留。没有为后台服务引入依赖。包公开 TS/TSX 源码，消费方使用 Bun、GPUIX JSX 宿主和已固定依赖；不直接运行 DOM React 组件库。

## 使用方职责

业务数据、后端筛选与排序、保存视图/偏好存储、身份认证、权限、文件读写与上传、邮件/聊天/AI、任务调度和云协作由应用提供。示例使用内存数据；未注入宿主功能明确返回 unsupported。高级业务服务不属于本版未完成组件。

## 保留的 UI 路线与平台限制

以下 UI 增强仍保留在[覆盖矩阵](../component-coverage.md)，属于后续组件路线：大规模虚拟化、通用拖放、滚动锚定、冻结列/分组聚合、高级富文本/代码编辑、嵌套筛选、完整日期时间/时区、系统材质/SF Symbols、系统菜单和完整 AX/IME。首版固定发布现有组件的已文档化能力，不声明这些增强已经完成。

本地原生验收平台为 macOS arm64、GPUIX React/native 0.7.0、React 19.2.4、Bun 1.4.2、TypeScript 5.9.3。Windows/Linux 原生、其他宿主版本未验证。中文真实输入的 smoke 不等于完整输入法兼容认证。GitHub CI 配置已提供，远端执行状态以仓库实际运行结果为准。
