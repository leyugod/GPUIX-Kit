# 0.19.0 · 补齐 UI 组件目录

用户要求：补齐缺失的所有 UI components 后，才能提交 GitHub。本版以[逐项目录](../untitled-ui-coverage.md)作为首版组件范围；替代 0.18.0 自行收窄的冻结清单。覆盖官网 30 类基础、37 类应用及 18 类营销组件，共 85 个目录类别。

新增身份/展示、验证码/评分、页面区块/步骤、二维码、渐变、仪表/加载/雷达、轮播/图片/视频控制/上传界面、富文本分块编辑、事件日历和营销区块。所有类别都映射到公开组件；已有组件保留此前 API。具体契约与宿主差异见[本批指南](../../packages/uikit/docs/catalog-completion.md)。

这是组件封装与适配接口交付。媒体画面/解码和系统文件服务需要注入，富文本默认是分块编辑；不宣称与浏览器富文本引擎、每个商业设计变体或所有平台等价。全页应用/营销示例不是组件类别，未作为业务产品移植。

本版提交到 [leyugod/GPUIX-Kit](https://github.com/leyugod/GPUIX-Kit)，远端记录以 Git 历史和 Actions 为准。本版[验收记录](validation-0.19.0.md)已通过 check:catalog、57 个原生脚本、独立安装和源码归档复验；不再用“现有组件可打包”替代目录完整性验收。当前包版本 0.19.0，GPUIX/native 固定 0.7.0，React 19.2.4，Bun 1.4.2；npm 未发布。
