# Component handbook · 0.20.0

[Quick start](../getting-started.md) · [Full API index](../api-index.md) · [Apple sidebar guide](../../packages/uikit/docs/sidebars.md)

Run `bun run dev` for native previews, search, Props and copyable JSX in one window. All 85 reference categories below have runnable examples and both theme previews. Supporting primitives, models and adapters remain in the API index.

Naming follows the [Untitled UI directory](https://www.untitledui.com/react/components) and [searchable icon resources](https://www.untitledui.com/resources/icons). Existing public PascalCase exports stay compatible; category identifiers use kebab-case. Visuals use the kit's Darwin themes.
